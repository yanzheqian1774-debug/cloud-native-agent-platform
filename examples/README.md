# Examples

For the fastest deterministic First Value, start with the root
[Quick Start](../README.md#quick-start).

For deeper control-plane behavior, use the
[Golden Engineering Demo](golden-engineering-demo/README.md). It covers:

- successful Agent, standalone Task, and four-node Workflow execution;
- dependency result propagation;
- a genuine retryable network failure and retry exhaustion;
- an independent successful branch and skipped dependent node; and
- read-only Kubernetes and Console inspection.

The examples use the current built-in mock provider and require no external
model credentials.
