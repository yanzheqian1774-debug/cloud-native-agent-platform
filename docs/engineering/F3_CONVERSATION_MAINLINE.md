# F3 conversation mainline — G1 implementation plan

Authorized 2026-11-10. Frozen V6.9-F3 and its state supplement are the visual baseline; SSO excluded. OpenClaw remains isolated and disabled. P0 installed source 851858b5e2ed remains the rollback baseline.

Scope: presentation composition only, reusing existing private conversation, journey journal, Native progress/answer and prepared result owners. Add optional DOM presentation slots for right-hand progress and fixed composer, without moving command ownership. Preserve legacy consumers when slots are absent. Preserve exact conversation/question/session-scoped answer drafts; do not infer facts or preselect options. Show bounded question choices only when explicitly quoted alternatives exist in the actual question. Prevent duplicate answer submissions while awaiting authoritative readback, and stop submitting on expiry or stale identity. No new model calls for progress. Keep concrete results/citations visible and collapse technical detail.

Validation: current frontend lint/build, existing conversation regressions, new browser cases for fixed composer/right rail, source confirmation, streamed preview, question draft refresh, duplicate clicks, expired/stale question, narrow layout and result visibility. Real installed same non-tabular question must reach original-conversation result with exact backend receipts, budgets and no replay of historical UNKNOWN. Compare actual pages to frozen F3. Existing unit or prototype evidence does not establish installed acceptance.

No public CRD/schema, authorization or budget policy change; no new persistence infrastructure. UI view state never grants access or determines completion. General goal revision, all management screens and unrestricted computer operation remain later stages.

Prototype-owner review incorporated: historical clarification is labeled answered after an authoritative answer exists; receipt text points to “本次工作”; duplicate goal elaboration and scope details collapse after success. Narrow-screen progress uses an explicit expandable region so the current answer remains visible. Read-denied progress removes the stale progress payload and answer action; transport-only failure retains the last observed progress. An uncertain answer submission is not automatically retried. A different goal after a completed run is still a later goal-revision increment, not implied by the fixed composer.
