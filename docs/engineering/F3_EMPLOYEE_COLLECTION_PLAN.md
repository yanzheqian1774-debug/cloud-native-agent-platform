# F3 employee collection presentation

Scope: existing employee collection and its existing exact-revision detail only.
The installed route audit identified that default detail is already the F3
business view, while the collection still presents the old split layout.

G1: present the default collection at full width, hide the unused detail pane,
and retain explicit revision choices, filtering, pagination, exact-read errors,
and the existing detail return. Professional mode retains the split layout.
Use the existing F3 colors, borders and spacing. This is a supporting collection
state, not a claim that the frozen prototype contains an identical collection.
No API, schema, authority, execution, model, or frozen prototype changes.

Validation: frontend lint/build; collection selection, filter/scroll return,
historical revision, mobile overflow and existing resource/employee regressions.
Candidate screenshots must be distinguished from installed screenshots. Submit
the collection and detail together for prototype review. Keep model policy
expiry and whole-platform acceptance gaps open.
