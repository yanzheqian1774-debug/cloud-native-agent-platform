# Limitations

- Sanitized, bounded supplier-quality Demo only.
- Internal Technical Preview; not certification, production readiness or release acceptance.
- Native Runtime only.
- Journey, intervention, feedback and SSE state is process-local and in memory.
- No durable or cross-process SSE replay, HA, exactly-once or multi-node guarantee.
- No external Runtime, OpenClaw, Hermes, Solution Blueprint, generated Native
  Agent, similar-problem retrieval, Package 6B, deployment, enterprise
  Knowledge, certification, production readiness or release acceptance.
- Live mode never falls back to fixtures or synthetic citations.
- Package 9 is deferred to the final v0.2.2 release stage.
- Controlled public-demo deployment is separate and unstarted.
- Knowledge is one bounded read-only Pack; no ingestion, vector database,
  production RAG, writeback or enterprise Knowledge operations are claimed.
- Browser evidence is sanitized and demonstrates only the tested viewports,
  locales and current exact baseline.
