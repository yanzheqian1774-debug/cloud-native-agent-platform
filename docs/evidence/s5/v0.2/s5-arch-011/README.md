## Decision evidence

The architecture candidate defines the bounded v0.2 path from a business question
through immutable Intent and approved canonical Workflow revisions, deterministic
authorization-first descriptor and published-role matching, declared Native placement,
authorized read-only Knowledge retrieval, append-only Evidence, sibling Product and
Technical projections, business-semantic correction, and immutable succession.

The decision preserves these safety boundaries:

- model output is proposal only;
- exact-digest Human approval precedes publication and execution;
- only existing `PUBLISHED/MATCHABLE` Definitions participate in v0.2;
- `RoleCandidatePreview` is non-executable and non-matchable;
- only an already declared Native target can be selected;
- Knowledge authorization precedes source/chunk retrieval;
- denied Knowledge has zero influence and zero source-existence disclosure;
- Product and Technical projections preserve the same citation identities;
- live execution cannot substitute synthetic Evidence or citations;
- MCP is transport only and is not Knowledge authority;
- Product correction produces an immutable successor rather than rewriting history.
