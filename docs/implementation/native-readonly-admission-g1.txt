Validation and publication boundary (2026-11-21)
- Resource tests deliberately execute a separate computation-test identity. Their
  receipts say READ_ONLY_OPERATION_COMPUTATION and NOT_RUN_REQUIRES_NATIVE_ATTEMPT;
  they never call a model or constitute autonomous business execution evidence.
- Native execution uses the selected registered executor and the original
  NativeLoopRuntime. The runtime sends exact adapter/answer schema in context;
  current authority is rechecked at each decision/tool step. New resource drafts
  have a bounded 480000 ms operation ceiling (same ceiling as existing document
  Native resources), not an extension of any grant, context or allowance deadline.
- A SUCCEEDED label or raw tool observation cannot produce a report projection:
  NativeDataSkillExecutor rebuilds the independent expected report, verifies all
  original-row observations and FINISH answer, and seals nativeReportVerification.
  The UI consumes only that server-verified field from authorized artifacts,
  checking matching source/adapter/report identity; immutable artifact bytes stay.
- This revision is synchronous Native data execution, NOT document v7 and NOT
  durable typed-question support. 0078 integration requires an explicit successor;
  do not replace its executor tuple with this adapter or claim delegated answers.
