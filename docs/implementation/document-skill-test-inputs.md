# Published document-rule test input adapter

G1 bounded adaptation of existing resource preparation owners. The published v4
skill requires ontologyContent and businessSemantics on every operation; the
existing automatic test builder omitted both and failed before invocation.

Resolve only the existing read-only work policy's exact subject, problem and
source-content binding. Require the existing policy grant owner to authorize
BUSINESS_ONTOLOGY READ before reading the pinned published ontology; preserve
revision/digest/source/scope checks and validate the rule/source adapter. Pass
these same inputs through the existing actual skill test owner. Do not loosen
schemas, publish revisions, edit old tests, invoke a model or claim Native
reasoning acceptance. Keep the original Plan and existing resource receipt.

Regression scope: published rule-bound and ordinary document actual computation,
missing/expired/wrong binding and denied reads, unchanged published resource
records, and existing sales resource preparation. Deployment and real request
recheck remain parent-owned; isolated tests are not live acceptance.

Deployment prerequisite: the current generation must permit BUSINESS_ONTOLOGY
READ requests with purpose RESOURCE_PREPARATION. This code does not add that
requestability rule or borrow a different purpose. The selected ontology remains
limited by the exact existing work binding. Preserve credential, expiry, budget
and old records when the deployment owner activates the approved configuration.
No migration, frontend rebuild or model configuration change is required.

Validation uses real isolated PostgreSQL resource/ontology owners and published
v4 resource content. Fixture publication approvals and the grant decision
boundary are controlled test setup, not real administrator acceptance. Actual
resource computation runs through the existing skill test owner; Native model
reasoning remains explicitly NOT_RUN_REQUIRES_NATIVE_ATTEMPT.
